# Editor Cerita Interaktif

Editor cerita interaktif dalam satu berkas HTML tanpa dependensi. Kamu bisa menulis bagian-bagian cerita, menyambungkannya lewat pilihan, melihatnya sebagai peta, menambahkan logika lewat skrip (dari perintah sederhana sampai JavaScript), memainkan hasilnya langsung, dan mengekspornya sebagai game HTML mandiri atau cadangan JSON.

## Cara menjalankan

1. Unduh atau clone repo ini.
2. Buka `index.html` di browser (klik dua kali, tanpa server atau instalasi).
3. Di tab **Pustaka**, buat cerita baru atau tekan **Muat cerita contoh**.
